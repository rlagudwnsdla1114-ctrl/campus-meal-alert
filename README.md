# 학식 선호 반찬 맞춤 알림 앱

## 프로젝트 소개

사용자가 좋아하는 음식이나 반찬을 등록하면 조식, 중식, 석식 메뉴와 비교하여 같은 음식이나 비슷한 반찬이 나오는 경우 알려주는 모바일 앱이다.

매일 학식 식단표를 확인하기 귀찮은 학생이 좋아하는 메뉴가 나오는 날을 쉽게 알 수 있도록 하는 것이 목적이다.

AI를 이용하여 이름이 정확히 같은 음식뿐만 아니라 비슷한 음식도 추천한다. 예를 들어 제육볶음을 좋아하는 사용자에게 고추장 돼지불고기를 추천할 수 있다.

추천받은 음식이 마음에 들지 않는 경우 '싫어요'를 선택할 수 있으며 해당 음식은 이후 추천에서 제외한다.

## 현재 진행 상태

PBL 팀 프로젝트의 GitHub 협업 환경을 준비하는 단계이다. 기술 스택은 아직 정하지 않았으며, 앱 화면·AI·데이터 저장·알림 기능은 구현하지 않았다. 기술 스택을 결정한 뒤 팀원들이 담당 브랜치에서 개발을 시작한다.

## 개발 시작 방법

Collaborator 초대를 수락한 뒤 저장소를 복제한다.

```bash
git clone https://github.com/rlagudwnsdla1114-ctrl/campus-meal-alert.git
cd campus-meal-alert
git switch -c youngwoong origin/main
```

강영웅과 강서원은 마지막 줄의 브랜치 이름을 본인의 담당 브랜치로 바꾸어 생성하고, 최초 push 시 `git push -u origin 브랜치이름`을 실행한다. 김형준은 이미 생성된 브랜치를 `git switch hyeongjun`으로 선택한다. 각자 Git 이름과 이메일을 확인한 뒤 작업한다.

```bash
git config user.name
git config user.email
```

자신의 브랜치에서 수정하고 커밋한 다음 같은 이름의 원격 브랜치로 push한다. main으로 Pull Request를 만들고 팀원과 확인한 뒤 김형준이 통합한다. 작업 전에는 최신 main 변경 사항을 자신의 브랜치에 반영하고, 충돌이 있으면 관련 팀원과 함께 해결한다.
